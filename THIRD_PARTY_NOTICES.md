Source-format references include the pinned official Meshtastic firmware listed in the [wire baseline](docs/research/meshtastic-wire-baseline.md). The adopted official schemas retain their upstream license; application-specific Nanopb options change only the bounded generated representation. This receiver is not an official Meshtastic SDK.

The build also uses platform C/C++ runtimes and system graphics, window, serial and USB frameworks. No SDRangel/SDR++ application runtime, GNU Radio, Python application runtime, web framework, map service or mesh-device API is required.


Archive and original-file hashes are in [UI provenance](third_party/ui-sources.json) and [SQLite provenance](third_party/sqlite-source.json). Reviewed local hashes are in [integrity.json](third_party/integrity.json); deliberate upstream-file changes are in [local-modifications.json](third_party/local-modifications.json).

The 2026-09-10 notice review extracted stb terms and the loader dedication from the pinned ImGui headers, retained the font/Khronos copyright notices with MIT terms, and extracted the SQLite dedication from the pinned public header. The libusb LGPL text was copied byte-for-byte from the installed 1.0.29 `COPYING`; these supplemental texts and the existing libhackrf header notice are now hash-inventoried. They do not establish a complete copyright inventory of the installed USB library binaries. Full source inspection, matching source delivery and platform packaging are still required before shipping those binaries. The HackRF distribution's root `COPYING` is GPLv2, while the selected public **libhackrf** header grants BSD-3-Clause; do not apply the header's terms to unrelated HackRF tools/firmware or infer complete library provenance from it.

The desktop **About & licenses** page and CLI `--licenses` display embedded local texts without accessing the network. Installation also supplies the selected original texts and a self-contained `LICENSES.txt`. Markdown source links in the inventory are references, not a promise that corresponding source is already publicly hosted.

Before binary distribution, include the corresponding source/build scripts and complete notices for the precise libraries actually shipped, resolve any additional platform dependencies, and meet GPL/LGPL/Apache/MIT/zlib obligations. Acknowledgments alone do not satisfy source-distribution requirements. No public release is made by this repository change.
